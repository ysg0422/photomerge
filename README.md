# PhotoMerge · 本地拼图工具

一个单文件的本地图片拼接工具，纯前端 Canvas 实现，不上传图片、不依赖任何后端。

打开 `index.html` 即可使用。

## 功能

- 拖拽、点击选择、`Ctrl+V` 粘贴图片
- 拖动缩略图调整顺序，单张删除
- 四种布局：
  - 横向拼接：统一高度，按比例
  - 纵向拼接：统一宽度，适合长图
  - 网格拼图：自定义列数、单元格比例、裁切/完整显示
  - 智能拼接：按原图 1:1 自动分列，不裁切、不缩放，自动选填充率最高的列数
- 智能拼接支持画布比例：自由、1:1、4:3、3:4、16:9、9:16、3:2、2:3
- 原图画质 1:1 / 自定义尺寸两种输出方式，自定义尺寸会提示缩放比例
- 画布上点选单张图片，拖四角等比缩放，或用底部滑杆 10%–300% 调整
- 可调图片间距、外边距、圆角、背景色
- 导出 PNG / JPEG / WebP
- 压缩导出：勾选后自动导出 JPG，按目标 KB 自动降低画质逼近大小，不缩小分辨率
- 一键清空，8 秒内可撤销

## 使用

```text
直接双击 index.html，或拖进浏览器。
```

图片只在浏览器内存中处理，不会上传到任何服务器。
