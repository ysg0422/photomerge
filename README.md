# PhotoMerge · 本地拼图工具

一个单文件的本地图片拼接工具，纯前端 Canvas 实现，不上传图片、不依赖任何后端。

打开 `index.html` 即可使用。

## 功能

- 三种导入方式：拖到页面任意位置、点击选择、`Ctrl+V` 粘贴
- 快捷模板：九宫格、双列长图、横版拼图、智能长图，一键套用
- 缩略图拖拽排序，也可用上下移按钮；单张删除
- 四种布局卡片，悬停即可在画布上即时预览：
  - 横向拼接：统一高度，按比例
  - 纵向拼接：统一宽度，适合长图
  - 网格拼图：列数步进器、单元格比例、裁切/完整显示
  - 智能拼接：按原图 1:1 自动分列，不裁切、不缩放，自动选填充率最高的列数
- 智能拼接支持画布比例：自由、1:1、4:3、3:4、16:9、9:16、3:2、2:3
- 原图尺寸 1:1 / 自定义尺寸两种输出方式
- 画布上点击选中图片，拖四角等比缩放，或用底部滑杆 10%–300% 调整，单张旋转 90°（快捷键 `R`）
- 裁切焦点：在「裁切填满」模式下直接拖动图片即可选择露出区域，底部按钮一键恢复居中
- 画布缩放：适配窗口 / 放大缩小 / `Ctrl + 滚轮`
- 可调图片间距、外边距、圆角、背景色，支持透明背景（PNG / WebP 保留透明，JPEG 自动填白）
- 撤销 / 重做（`Ctrl+Z` / `Ctrl+Shift+Z`），覆盖增删、排序、布局与样式修改
- 单张图片压缩：选中图片后可选择目标大小（100 KB / 300 KB / 500 KB / 1 MB 或自定义），压缩完成先预览结果，点「应用」才会替换原图，「取消」保持原样；目标过小时会自动降低分辨率并在结果中说明
- 导出 PNG / JPEG / WebP，或直接复制图片到剪贴板；压缩导出按目标 KB 自动降低画质，不缩小分辨率
- 预览自动降采样保证拖动流畅，导出始终按完整分辨率重新合成
- 一键清空可撤销，一键恢复默认设置

## 使用

```text
直接双击 index.html，或拖进浏览器。
```

图片只在浏览器内存中处理，不会上传到任何服务器。
